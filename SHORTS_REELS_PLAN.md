# Shorts & reels — the full briefing topic list

Every daily briefing topic on the roadmap, laid out so a short or a reel can ship next to the briefing on the same morning. **240 topics** — 90 foundations (days 1–90) and 150 industry pieces across 30 verticals (days 91–240).

> Generated by `tools/build_shorts_reels_plan.py` from `roadmap/90_day_roadmap.csv` and `roadmap/day_91_240_enriched.csv`. Edit the roadmap, re-run the script — don't hand-edit this file.

Working copy for production tracking: **`roadmap/shorts_reels_master.csv`** (one row per day, with `short_status` / `reel_status` / `asset_link` / `posted_at` / `notes` columns to fill in). Re-running the generator preserves whatever you've typed into those five columns.

## How to use this

Each briefing already contains the three lines a 30-second video needs, so nothing here is newly written — it's the briefing's own copy, re-cut for camera:

| Roadmap field | Job in the video |
|---|---|
| `topic` | The title card — what this one is about |
| `concept` → **Hook** | First 3 seconds. The claim, stated flat. |
| `clarification` → **Stakes** | Middle. The everyday detail that makes it land. |
| `save_worthy_takeaway` → **Verdict** | Final frame. Built to be screenshotted. |

### The 30-second skeleton

```
0:00–0:03   HOOK      concept, on screen and spoken
0:03–0:12   STAKES    clarification — one concrete example, no law-quoting
0:12–0:22   VERDICT   save_worthy_takeaway, held still on Trust Navy
0:22–0:30   CTA       stage CTA + 'full briefing in the link'
```

Keep reels under 40s and shorts under 60s. If a topic won't fit, it's a carousel, not a reel.

### Treatment by format

| Format | Count | How to shoot it |
|---|---:|---|
| **Stat** | 41 | One number on a Trust Navy card, held for a beat before the voice starts. Number → what it means for the viewer's business → verdict. No b-roll. |
| **Explainer** | 63 | Talking head with one on-screen phrase per sentence. Claim, then the everyday example that proves it, then the verdict. Cut every filler word. |
| **Checklist** | 87 | Screen-recorded list that builds line by line as it is read. 3-5 items, never more. Final frame holds the whole list still so it can be screenshotted. |
| **Playbook** | 49 | Numbered steps with a timer or day-marker in the corner. Show the order of operations, not the theory. End on step 1 so the viewer can start today. |

### Caption + CTA

One primary action per video, matched to the stage so the reel and the briefing card send people the same way:

| Stage | What the viewer needs | CTA in the caption |
|---|---|---|
| Learn | Understand the law | **Check my readiness** → `/assessment` |
| Assess | Check my risk | **Map my data** → `/discovery` |
| Fix | Take action | **Get the checklist** → `/resources` |
| Sustain | Maintain readiness | **Browse templates** → `/resources` |

Caption shape: verdict line → one-sentence why → CTA → link to the briefing → `@saralprivacy`. Sentence case, active voice, no fear theatre, and never the phrase "legal compliance".

### Posting it adjacent to the briefing

1. The pipeline publishes the briefing at **09:00 IST**; the reel goes out the same morning, after the briefing URL exists.
2. Caption links to `https://saralprivacy.com/briefings/<slug>` — put the slug in the CSV's `briefing_url` column as each day goes live, so the sheet stays the join between video and page.
3. Reuse the day's infographic as the reel's end card — same claim, same colours, one asset doing two jobs.
4. Record a vertical in sector blocks, not day by day: days 91–240 run five consecutive days per vertical, so one sitting produces a week of a single audience's content.
