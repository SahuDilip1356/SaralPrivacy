## Conventions / reuse (don't reinvent)
- DB = **Appwrite** (`databases`, `DB_ID`, `COLLECTIONS`, `ID`, `Query`). Spam = `lib/abuseGuard.ts`. Email =
  `lib/email.ts` (Resend). Validation = `zod`. Analytics = GA (`lib/analytics.ts`). Clone routes from
  `app/api/subscribe/route.ts`.
- v2 data spine = **`lib/discovery`** (23 categories · 276 niches · 182 item defs · 18 risk tags;
  `resolveGroups(nicheId)` → scoped items with purposes/tags/obligations). High-care = `TAG_LIB` weight ≥3.
- Engine is **deterministic, no LLM**. Guardrails: consent **§6 not §7**; only the **five DPDPA rights**
  (no GDPR portability/restriction/object); say **"high-care"** not "sensitive"; never "compliant"; never
  store real Aadhaar/PAN/health values (categories only).
